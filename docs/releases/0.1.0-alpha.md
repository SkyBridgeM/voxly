# Voxly 0.1.0-alpha

Voxly 的首个可安装桌面测试版，适用于 Apple Silicon（M 系列芯片）Mac。安装包已包含 FFmpeg 9.0.2，无需另装 Homebrew、Python 或 Go。

## 主要更新

- 本地 SenseVoice 中文转写，支持导入 M4A、MP3、WAV；安装模型后，转写无需 API Key。
- 可选 VAD 按讲话停顿分段，输出全文、带时间转写与结构化分段数据。
- 任务取消和恢复，已完成片段复用。
- 任务库、版本化内容生成和自定义模板。
- 存储统计、音频切片清理、手动“仅保留文本”；删除范围在执行前预览，外部原文件不删除。
- 设置按通用、识别与生成、模型与连接、内容模板、存储、关于与诊断分类。
- 内置独立 FFmpeg 9.0.2，无需安装 Homebrew、Python 或 Go。

## 安装与首次使用

1. 下载适用于 Apple Silicon Mac 的 DMG，打开后将 Voxly 拖入 Applications。
2. 启动 Voxly，在设置的“模型与连接”中安装 SenseVoice 模型。首次模型下载需要联网。
3. 在“识别与生成”中选择本地语音识别，确认中文／自动语言和 VAD 选项，保存。
4. 导入录音并选择“转写”。结果可在任务库打开。

## 测试版边界

- 本次构建仅做本地 ad-hoc 签名，未使用 Apple Developer ID 签名或公证，macOS 可能阻止首次启动。不要把本包描述成已公证版本；对来源或内容有疑问时不要运行。
- 当前只发布 Apple Silicon Mac；Intel、Windows 尚未提供本次验收的安装包。
- 没有内置麦克风录音和实时流式识别；输入是已录制文件。
- 时间戳是讲话片段边界，不是逐字时间戳；CAM++ 尚未接入，不区分说话人。
- MiMo 云端识别需要凭据并上传音频；DeepSeek 内容生成需要凭据并上传转写文字。本地转写不等于云端生成也离线。
- “仅保留文本”无法撤销。确认转写后再删除任务内音频；重新识别或回听需要另有录音副本。
- 安装包已在本机取出并启动，尚未在另一台全新 Mac 上试装。
