# Voxly 0.1.0-alpha

This is the first installable Voxly desktop Alpha for Apple Silicon Macs. The
DMG includes FFmpeg 9.0.2, the Go core and the native recognition runtime.
Users do not need Homebrew, Python or Go.

## What's included

Local SenseVoice transcription accepts M4A, MP3 and WAV. Chinese is the default;
automatic language detection is available. Install the model through Settings
before the first local transcription. Recognition then runs without an API key.

Optional VAD segments speech around pauses and saves a timed transcript and
segment JSON alongside the full text. Tasks can be cancelled and resumed with
completed text checkpoints intact.

The Task Library keeps generated content in separate versions. Settings has
categories for appearance, transcription, models, templates, storage and
diagnostics. Storage tools show disk usage and preview cleanup. Keep text only
removes a completed task's own audio after confirmation, retaining text, timing
data and generated versions. It does not delete the external imported file.

## Install

Open the DMG and drag Voxly into Applications. Download or import SenseVoice in
Models & connections, choose local recognition in Transcription, save, then
import a recording.

This build has local ad-hoc signatures, but no Apple Developer ID signature or
notarization. macOS may block it. Verify the download source and SHA-256 values
before use. The package has been extracted and launched locally; installation
on a separate clean Mac has not yet been checked.

## Limits

This release has no microphone recording, streaming recognition or speaker
labels. Times describe speech intervals rather than individual words. CAM++ has
only a reserved code interface.

MiMo cloud recognition sends audio to MiMo. DeepSeek generation sends transcript
text to DeepSeek. These services require their own credentials. Local recognition
does not make an optional cloud generation step offline.

Keep text only cannot be undone. Check important transcript passages and retain
another audio copy if you need playback or retranscription. This release has no
validated Intel Mac or Windows installer.

The release includes the DMG, SHA-256 values, and matching FFmpeg/LAME sources
with build instructions. Dependency notices are inside the app under
`Contents/Resources/licenses`.
